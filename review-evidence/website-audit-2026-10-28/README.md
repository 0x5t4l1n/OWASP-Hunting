# Website audit issue screenshots — 2026-10-28

Baseline: OWASP/OWASP-Hunting website at ac81655f4ac3aa1250023a3a9a5e3a93c00ac059.

All screenshots were captured locally in Chromium at 1366x900. Red rectangles, numbered labels, and panels headed AUDIT ANNOTATION are temporary browser overlays added solely to explain the evidence. They are not website UI changes or implemented features. No website source was modified for these reports and no PR is being opened from this evidence-only branch.

- `doc-blockquote-rendering-marked.png`: /docs/installation/ contains markdown blockquote `> The upstream OWASP repository...`. In the rendered DOM, it appears as `<p><br>&gt; ...</p>` without an enclosing `<blockquote>`. CSS in `globals.css` targeting `.prose blockquote` is never applied.
- `broken-contributors-link-marked.png`: /community/ includes a link to "Contributors Hall of Fame" pointing to `https://github.com/owasp/owasp-hunting/blob/main/CONTRIBUTORS.md`. The target file does not exist in the repository, resulting in an HTTP 404 response on GitHub.
- `payload-card-truncation-marked.png`: /payloads/ displays vulnerability category cards. The description paragraphs have an inline style `maxWidth: "200px"`, causing text like "Database query manipulation through unsanitized input" to truncate with an ellipsis even when 60px+ of horizontal space remains inside the card, and without a `title` tooltip.
- `search-quick-links-mismatch-marked.png`: Modal Search component (`src/components/ui/Search.tsx:86`) filters default quick links using exact titles `["Getting Started", "SQL Injection", "XSS", "SSRF", "Contributing"]`. In `src/lib/search-data.ts`, they are titled `"Cross-Site Scripting (XSS)"` and `"SSRF (Server-Side Request Forgery)"`. Consequently, XSS and SSRF are silently dropped and only 3 items display.
- `not-found-missing-title-marked.png`: `src/app/not-found.tsx` defines no metadata export or title tag. When navigating to 404 routes, the browser tab displays generic fallback title `"OWASP Hunting — Security Testing Documentation"`, violating WCAG 2.4.2 (Page Titled).
- `toc-border-zero-padding-marked.png`: In `src/components/layout/TableOfContents.tsx:80, 87`, Level 2 TOC items have `paddingLeft: "0"`, and dynamic padding was commented out. When an item becomes active, the 2px accent border collides flush into the heading text without horizontal separation.
- `contributing-clone-push-mismatch-marked.png`: `src/app/contributing/page.tsx:143-165` instructs contributors in Step 1 to clone the upstream repository (`git clone https://github.com/owasp/owasp-hunting.git`) and in Step 3 to run `git push origin add-xss-payloads`, which causes an HTTP 403 Permission Denied fatal error because external contributors lack push permissions to upstream `origin`.
- `docs-prose-extraneous-br-marked.png`: In `src/app/docs/[slug]/page.tsx:196-198`, `renderMarkdown` replaces `\n\n` with `</p><p>` followed by `\n` with `<br/>`. This generates empty `<p></p>` elements between headings and paragraphs, and invalid `<br>` tags inside `<ul>` elements between `<li>` items.
